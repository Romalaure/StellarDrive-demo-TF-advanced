# Model sources (not in the repository)

- `kenney_nature/`: **Nature Kit** by Kenney, www.kenney.nl, license CC0 (public domain).
  Download https://kenney.nl/assets/nature-kit and unzip it here so that
  `kenney_nature/Models/GLTF format/*.glb` exists. Only the scenes built from it
  (`src/StellarDriveDemoTFAdvanced/Models/nature_*.obj`) are in the repository.
