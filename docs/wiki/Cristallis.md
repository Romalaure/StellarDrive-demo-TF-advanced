# Cristallis

*Système : [galaxie d’Érèbe](Galaxie-Erebe.md)*

| | |
|---|---|
| Biome | cristalline : plaines de sel lilas, crêtes acérées, anneau de cristal |
| Gravité | 0,6 g |
| Air | trop mince |
| Flore | aucune |

## Ressources

- quartz (beaucoup)
- cryonite
- météorite
- astéroïdes de cristal

## Lieux

- ruines de glace
- épaves
- épave du Léviathan (en orbite)

## Utilité

Quartz et cryonite en masse ; gravité faible.

> ⚠️ Air trop mince : oxygène obligatoire.
