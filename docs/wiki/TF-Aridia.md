# TF Aridia

*Système : [442 Otrera](Systeme-Otrera.md)*

| | |
|---|---|
| Biome | désert : dunes, mesas rouges, lacs salés, ciel ambré |
| Gravité | 0,9 g |
| Air | respirable |
| Flore | acacias, arbres morts, herbe sèche |

## Ressources

- quartz
- uranium
- fer
- cuivre
- verre

## Lieux

- ruines en grès (portes, piliers, obélisques)
- villages et temples (coffres)
- épaves, cargos écrasés
- Avant-poste Orion tout près

## Utilité

Quartz ; fragments d'artefact dans les coffres des temples.
