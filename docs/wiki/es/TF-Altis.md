# TF Altis

*Sistema: [442 Otrera](Systeme-Otrera.md)*

| | |
|---|---|
| Bioma | montañas de hasta 8 km, nieve por encima de 1.400 m, lagos glaciares |
| Gravedad | 1,1 g |
| Aire | respirable |
| Flora | pinos densos, bosquecillos de abedules (verdes y otoñales) |

## Recursos

- titanio
- madera

## Lugares

- ruinas y pueblo de granito

## Utilidad

Titanio y madera; grandes vistas.
