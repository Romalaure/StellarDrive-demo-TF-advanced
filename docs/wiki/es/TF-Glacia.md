# TF Glacia

*Sistema: [442 Otrera](Systeme-Otrera.md)*

| | |
|---|---|
| Bioma | glacial: casquetes de hielo, montañas de 9 km, lagos helados, anillo pálido |
| Gravedad | 1 g |
| Aire | respirable |
| Flora | abetos escarchados, árboles secos |

## Recursos

- criónita
- titanio
- asteroides

## Lugares

- ruinas y pueblo atrapados en el hielo
- restos, cargueros
- agujero negro de Glacia a 4.100 km

## Utilidad

Criónita: batería de criónita, condensador, campo de fuerza.
