# TF Verdance

*Sistema: [442 Otrera](Systeme-Otrera.md)*

| | |
|---|---|
| Bioma | templado, grandes lagos, bosques |
| Gravedad | 0,95 g |
| Aire | respirable |
| Flora | abetos, robles, abedules, hierba espesa |

## Recursos

- ámbar
- madera (robles, abedules, abetos)

## Lugares

- ruinas cubiertas de musgo
- pueblos
- restos, cargueros
- Estación Kepler

## Utilidad

Primer destino fácil: ámbar, madera, cofres de los pueblos.
