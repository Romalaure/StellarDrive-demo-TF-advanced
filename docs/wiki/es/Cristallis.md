# Cristallis

*Sistema: [galaxia de Érebo](Galaxie-Erebe.md)*

| | |
|---|---|
| Bioma | cristalino: llanuras de sal lila, crestas afiladas, anillo de cristal |
| Gravedad | 0,6 g |
| Aire | demasiado tenue |
| Flora | ninguna |

## Recursos

- cuarzo (mucho)
- criónita
- meteorito
- asteroides de cristal

## Lugares

- ruinas de hielo
- restos
- restos del Leviatán (en órbita)

## Utilidad

Cuarzo y criónita en abundancia; gravedad baja.

> ⚠️ Aire demasiado tenue: oxígeno obligatorio.
