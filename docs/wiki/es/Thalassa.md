# Thalassa

*Sistema: [galaxia de Érebo](Galaxie-Erebe.md)*

| | |
|---|---|
| Bioma | oceánico: islas de arena blanca en un océano turquesa |
| Gravedad | 0,9 g |
| Aire | respirable |
| Flora | palmeras, hierba de isla |

## Recursos

- cuarzo
- ámbar
- madera de palmera

## Lugares

- pueblos y ruinas de arenisca en las islas
- restos
- restos del Vagabundo (en órbita)

## Utilidad

Una base tranquila en Érebo: aire respirable, madera y cuarzo.

Ver también: [Recursos](Ressources.md), [Mesa de cartografía](Machines.md#mesa-de-cartografía) (muestra esta ficha en el juego).
