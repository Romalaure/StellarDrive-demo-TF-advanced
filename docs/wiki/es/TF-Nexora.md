# TF Nexora

*Sistema: [442 Otrera](Systeme-Otrera.md)*

| | |
|---|---|
| Bioma | futurista: llanuras oscuras, lagos turquesa, cielo violeta, ciudad abandonada |
| Gravedad | 0,85 g |
| Aire | respirable |
| Flora | árboles cian, hierba turquesa |

## Recursos

- núcleo cuántico
- aleación nexoriana
- cuarzo

## Lugares

- ciudad: rascacielos y torres en los que se puede entrar, cúpulas, plazas, coches voladores, quioscos

## Utilidad

La fuente regular de núcleos cuánticos y aleación, en los cofres de los rascacielos.
