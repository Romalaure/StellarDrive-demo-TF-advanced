# TF Aridia

*Sistema: [442 Otrera](Systeme-Otrera.md)*

| | |
|---|---|
| Bioma | desértico: dunas, mesetas rojas, lagos de sal, cielo ámbar |
| Gravedad | 0,9 g |
| Aire | respirable |
| Flora | acacias, árboles secos, hierba seca |

## Recursos

- cuarzo
- uranio
- hierro
- cobre
- vidrio

## Lugares

- ruinas de arenisca (puertas, pilares, obeliscos)
- pueblos y templos (cofres)
- restos, cargueros estrellados
- Puesto avanzado Orión cerca

## Utilidad

Cuarzo; fragmentos de artefacto en los cofres de los templos.
