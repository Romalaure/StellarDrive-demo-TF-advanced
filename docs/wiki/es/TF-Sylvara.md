# TF Sylvara

*Sistema: [442 Otrera](Systeme-Otrera.md)*

| | |
|---|---|
| Bioma | jungla: colinas húmedas, ríos cálidos, cielo brumoso |
| Gravedad | 1,05 g |
| Aire | respirable |
| Flora | ceibas gigantes de 30 m, árboles de dosel, palmeras, helechos, flores |

## Recursos

- ámbar
- madera en abundancia

## Lugares

- templos y pueblos cubiertos de musgo
- restos, cargueros

## Utilidad

Madera, ámbar, artefactos de los templos.
