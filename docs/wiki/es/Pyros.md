# Pyros

*Sistema: [galaxia de Érebo](Galaxie-Erebe.md)*

| | |
|---|---|
| Bioma | volcánico: basalto negro, laderas oxidadas, lagos de lava, cielo rojo |
| Gravedad | 1,2 g |
| Aire | tóxico |
| Flora | árboles calcinados con brasas brillantes |

## Recursos

- meteorito (mucho)
- titanio
- uranio

## Lugares

- ruinas de forja de basalto
- pueblo
- cargueros
- el agujero negro Ojo de Érebo a 2.500 km
- restos del Ícaro (en órbita)

## Utilidad

La mejor fuente de meteorito. Cerca del Ojo de Érebo, un colector de materia oscura va cinco veces más rápido.

> ⚠️ Aire irrespirable: oxígeno obligatorio. Gravedad fuerte.
