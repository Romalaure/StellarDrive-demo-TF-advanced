# Mycélia

*Sistema: [galaxia de Érebo](Galaxie-Erebe.md)*

| | |
|---|---|
| Bioma | fúngico: musgo morado, bosques de setas gigantes luminosas, niebla verde |
| Gravedad | 0,8 g |
| Aire | tóxico (esporas) |
| Flora | setas gigantes de 13 m, helechos de esporas, flores moradas y blancas |

## Recursos

- meteorito
- criónita
- madera de seta

## Lugares

- ruinas cubiertas de musgo
- cargueros

## Utilidad

Meteorito y criónita; las setas se talan como árboles.

> ⚠️ Esporas tóxicas: oxígeno obligatorio.
