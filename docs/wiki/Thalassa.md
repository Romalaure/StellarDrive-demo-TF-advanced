# Thalassa

*Système : [galaxie d’Érèbe](Galaxie-Erebe.md)*

| | |
|---|---|
| Biome | océanique : îles de sable blanc dans un océan turquoise |
| Gravité | 0,9 g |
| Air | respirable |
| Flore | palmiers, herbe des îles |

## Ressources

- quartz
- ambre
- bois de palmier

## Lieux

- villages et ruines en grès sur les îles
- épaves
- épave du Vagabond (en orbite)

## Utilité

Base tranquille dans Érèbe : air respirable, bois et quartz.
