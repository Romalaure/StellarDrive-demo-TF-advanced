# TF Glacia

*Système : [442 Otrera](Systeme-Otrera.md)*

| | |
|---|---|
| Biome | glaciaire : calottes de glace, montagnes de 9 km, lacs gelés, anneau clair |
| Gravité | 1 g |
| Air | respirable |
| Flore | sapins givrés, arbres morts |

## Ressources

- cryonite
- titane
- astéroïdes

## Lieux

- ruines et village pris dans la glace
- épaves, cargos
- trou noir de Glacia à 4 100 km

## Utilité

Cryonite : batterie à cryonite, condenseur, champ de force.
