# Mycélia

*Système : [galaxie d’Érèbe](Galaxie-Erebe.md)*

| | |
|---|---|
| Biome | fongique : mousse violette, forêts de champignons géants lumineux, brume verte |
| Gravité | 0,8 g |
| Air | toxique (spores) |
| Flore | champignons géants de 13 m, fougères à spores, fleurs violettes et blanches |

## Ressources

- météorite
- cryonite
- bois de champignon

## Lieux

- ruines moussues
- cargos

## Utilité

Météorite et cryonite ; les champignons se coupent comme des arbres.

> ⚠️ Spores toxiques : oxygène obligatoire.
